# Input PDF

The experiments use *Fundamentals of Database Systems*, 7th edition, by Ramez Elmasri and Shamkant B. Navathe.

1. Download the [PDF from Cleveland State University](https://eecs.csuohio.edu/~sschung/cis430/Fundamentals-of-Database-Systems-Pearson-2015-Ramez-Elmasri-Shamkant-B.-Navathe.pdf).
2. Rename it to `Fundamentals_of_Database_System.pdf`.
3. Place it in this folder: `data/raw/Fundamentals_of_Database_System.pdf`.

The PDF is excluded from Git.
